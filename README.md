# Evrenin En Ciddi Saçmalık Üreticisi 🌌👑

## ⚠️ DİKKAT: Bu repo son derece ciddidir. Ciddiye almayanlar sorumluluk kabul etmez. ⚠️

Bu proje, insanlık tarihinin en büyük sorularından birine cevap vermek için tasarlanmıştır:

> "Hayatın anlamı nedir?"

Cevap: **Saçma sapan rastgele Türkçe cümleler.**

### Özellikler (Abartılı Versiyon)
- Gerçekten çalışan Python kodu (inanmazsanız çalıştırın)
- Her çalıştırmada yeni bir felsefi devrim
- Yavaş çalışır çünkü düşünmek zaman ister (ve sleep() kullanır)
- %100 organik, GDO'suz saçmalık
- GitHub Copilot bile bunu ciddiye alır (belki)

### Nasıl Kullanılır?
```bash
python sacmalik_uretici.py
```

Çıktı örneği:
```
Kedi düşünüyor hayatın anlamını çünkü neden olmasın?
```

### Neden Bu Repo Var?
Çünkü birisi "saçma bir repo aç" dedi ve ben de çok ciddiye aldım.
Anlamlı olmasına gerek yoktu. Türkçe olması yeterliydi.

### Katkıda Bulunma
Pull request gönderin, belki kabul ederim. Belki etmem. Şansa bağlı.

### Lisans
Bu kod serbestçe kullanılabilir. Ama saçmalıkların telif hakkı evrene aittir.
